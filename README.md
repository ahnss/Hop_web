# HOP 한글 — 아이폰 웹앱

HWP/HWPX 문서를 보고 편집하는 HOP의 **웹앱 배포본**입니다(빌드 결과물만 들어 있음).

- 주소: https://ahnss.github.io/Hop_web/
- 아이폰: Safari로 열고 **공유 → 홈 화면에 추가**. 한 번 연 뒤에는 인터넷 없이도 열립니다.
- 문서는 기기 안에서만 처리되며 서버로 올라가지 않습니다.

소스와 사용 안내는 비공개 저장소 `ahnss/ahnss_project`의 `hop-android/`(IPHONE.md)에서 관리합니다.
이 저장소의 파일은 그 소스에서 자동 빌드한 결과라 직접 고치지 않습니다.

라이선스: HOP·rhwp MIT. 글꼴별 라이선스는 `fonts/` 원본 저장소의 FONTS.md를 따릅니다.
